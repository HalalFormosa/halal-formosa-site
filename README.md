# 🕌 Halal Formosa — Official Website

This is the official website for **Halal Formosa**, a Muslim-friendly ecosystem in Taiwan providing halal food discovery, ingredient scanning, prayer space locations, and travel guidance.

The website is built with:

- **Vue 3**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Vue Router**
- Hosted on **Vercel**

---

## 🚀 Features

- ✨ Modern single-page design
- 🧭 Smooth navigation with Vue Router
- 📱 Mobile-friendly responsive layout
- 📄 Privacy Policy & Terms of Service pages
- 📬 Working contact form (FormSubmit)
- 🔗 Links to App Store / Play Store (Android and iOS live)

---

## 🛠️ Tech Stack

- **Vue 3 + Vite** for fast development
- **TypeScript** for safer code
- **Tailwind CSS** for styling
- **Vue Router** for page navigation
- **FormSubmit** for contact form email handling
- **Vercel** for deployment and hosting

---

## 📦 Project Setup

### Install dependencies
```bash
npm install
```

### Run development server
```bash
npm run dev
```

### Build for production
```bash
npm run build
```

### Preview production build
```bash
npm run preview
```

---

## 📁 Project Structure

```
src/
 ├─ components/     # Reusable sections (Header, Footer, Hero, Pricing, etc.)
 ├─ pages/          # Static pages (Home, About, Contact, Privacy, Terms)
 ├─ router/         # Vue Router setup
 ├─ assets/         # Optional images / icons
public/
 ├─ logo.png        # Website favicon & hero icon
```

## 🌐 Deployment

The site is deployed on **Vercel**.  
Push to `main` branch → Vercel auto-builds and deploys.
